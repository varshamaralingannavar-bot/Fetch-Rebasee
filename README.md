# Fetch & Rebase Practice Project

This repository is dedicated to learning and practicing the essential Git workflows, including commits, pushing, and rebasing.

## 🚀 What I Learned
- Local repository setup and configuration
- Creating snapshots via commits
- Synchronizing local code with remote branches using `--rebase`
- Secure authentication via GitHub Credential Manager

## 🛠️ How to run the workflow
To save and push changes to this repository:
1. `git add .`
2. `git commit -m "Your commit message"`
3. `git push`
